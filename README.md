## 📌 Projetos em Destaque

### 🤖 Chatbot RAG com Wikipedia PT-BR

Sistema de Retrieval-Augmented Generation utilizando embeddings multilíngues, FAISS, OpenRouter API e interface Gradio para responder perguntas em linguagem natural.

### 🌊 Segmentação de Áreas de Inundação

Projeto de Visão Computacional para segmentação semântica de áreas alagadas em imagens aéreas e de satélite utilizando métricas como IoU e Dice Score.

### 👤 Reconhecimento Facial com Máscaras

Modelo baseado em Siamese Networks, ResNet18 e Triplet Loss para reconhecimento facial mesmo com o uso de máscaras.

### 💊 Predição de Diabetes com Machine Learning

Pipeline completo de análise e modelagem envolvendo tratamento de dados, SMOTE, engenharia de atributos e otimização de hiperparâmetros.

### 🌸 Sistema de Recomendação de Perfumes

Sistema híbrido utilizando TF-IDF e SVD para recomendação personalizada de perfumes nacionais.

### 📰 Coleta e Classificação de Notícias

Projeto em desenvolvimento utilizando scraping, PostgreSQL (Supabase), Streamlit e técnicas de NLP para classificação automática de notícias políticas.
